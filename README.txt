# Magische Kinderwelt – HTML/CSS/JavaScript Webseite

Enthalten:
- Mehrseitige Homepage für www.magische-kinderwelt.ch
- Home, Angebote, Prozess, Über uns, Onlineshop
- Dynamisches Formular für Weihnachten, Ostern, Geburtstag, Kommunion, 1. Schultag, Motivation
- Optionaler Audio-Input via Web Speech API im Browser
- Demo-Druckvorschau und Bestätigungsablauf
- Onlineshop-Demo mit 50 Produkten, Suche, Filter und Warenkorb-Zähler

Hinweis: Dies ist eine statische Frontend-Demo. Für echte KI-Brieferstellung, PDF-Erstellung, E-Mail-Versand, Onlinezahlung und Druck/Post-Versand brauchst du ein Backend.
