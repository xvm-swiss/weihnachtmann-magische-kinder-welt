# Magische Kinder Welt – Homepage (nur HTML/CSS/JavaScript)

Dieses Mini-Projekt enthält **nur eine Homepage** (Landingpage) – komplett ohne Supabase, ohne Frameworks.

Enthalten:
- `index.html`
- `assets/styles.css`
- `assets/app.js` (Dark/Light Mode + kleine Brief-Demo)
- `assets/logo.svg`

## Start

Einfach `index.html` im Browser öffnen.

## Anpassen

- Texte in `index.html` ändern
- Farben in `assets/styles.css` unter `:root` und `html.dark` anpassen
- Logo ersetzen: `assets/logo.svg`
